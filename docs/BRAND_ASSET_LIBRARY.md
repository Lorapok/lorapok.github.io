## Usage rules

- Use the master lockups when a full product name must remain legible.
- Use sensory-glass icons and compact marks only where the surrounding interface already identifies the product.
- Use the success and recovery mascots only for the matching workflow states.
- Preserve transparent backgrounds and aspect ratios.
- Do not overwrite an established character. Add a clearly named variant when a new role is required.
- Keep commercial product assets and open-source editorial claims in their correct universe.
