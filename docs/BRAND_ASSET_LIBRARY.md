# Lorapok Labs brand asset library

## Production character system

The production library contains 32 coordinated characters. Every earlier character remains available:

- six original Ribo moods;
- five restored Larva Sanctuary species;
- five operational Ribo roles;
- ten reference-grounded product-world roles;
- six context-aware inner-page companions.

The six companions are intentionally distributed away from the homepage:

| Companion | Public surface | Supporting source reference |
|---|---|---|
| Ecosystem Cartographer | `/projects` | Labs and LoraHost co-branded ecosystem strip |
| Formation Commander | `/agents` | Loragent orchestration language |
| Collective Facilitator | `/about` | Lorapok Labs identity system |
| Release Historian | `/changelog` | Lorapok Labs publishing system |
| Documentation Librarian | `/blog` | LoLaBo research system |
| Communications Concierge | `/contact` | Lorapok Labs identity system |

The rendered companion assets live in `public/assets/ribo/inner-pages/`. They retain the verified cream-and-green segmented larva body, leaf antennae, green eyes, translucent leaf panels, and navy field bag while adding role-specific tools.

## Approved source library

Eleven verified, reusable originals are copied into `public/assets/brand-library/` so the application never depends on removable drives or private workspace paths:

- Lorapok Labs: master lockup, sensory-glass icon, and Open Graph card;
- LoraHost: master lockup, sensory-glass icon, and launch campaign card;
- Automate: horizontal lockup, compact mark, success mascot, and recovery mascot;
- ecosystem: Lorapok Labs and LoraHost co-branded strip.

The private Office Brand Gallery can filter these assets by family, preview them, copy their stable public path, and download the approved file. Source-family labels describe provenance; they do not assert partnerships.

## Usage rules

- Use the master lockups when a full product name must remain legible.
- Use sensory-glass icons and compact marks only where the surrounding interface already identifies the product.
- Use the success and recovery mascots only for the matching workflow states.
- Preserve transparent backgrounds and aspect ratios.
- Do not overwrite an established character. Add a clearly named variant when a new role is required.
- Keep commercial product assets and open-source editorial claims in their correct universe.
